## Проект

Сквозной курсовой проект на теме аренды жилья в Украине:
- **ДЗ 1 (сдано, 29/30)** — Structured Extraction: извлечение JSON из объявлений об аренде.
  Код в `src/`, промпты в `prompts/`, данные в `data/ads/`, `data/golden.jsonl`, `data/sources.csv`.
  Замечание ментора: была подгонка под golden set — не повторять в ДЗ 2.
- **ДЗ 2 (сейчас, дедлайн 13.11 23:59)** — RAG на своих данных + evals в CI:
  документы → очистка → чанки + метаданные → векторная база (hybrid search + reranking)
  → ответ модели с источниками → evals в GitHub Actions.
- **ДЗ 3 (позже)** — агент на этом корпусе.

## Данные ДЗ 2

- Корпус: `data/raw/` — 31 документ (22 HTML в `html/`, 9 PDF в `pdf/`), все на украинском,
  про аренду жилья: закон (ЦК, глава 59), разъяснения ДПС, статьи о налогах.
- `data/raw/manifest.csv` — источник, название, тип (`law` / `article` / `dps` / `guide`),
  дата, заметки. Файлы ДЗ 1 (`data/sources.csv` и др.) не трогать.
- Известные особенности:
  - HTML содержит много boilerplate (меню, реклама) — нужна очистка;
  - в `ck_glava59_buhgalter911.html` тег `<h1>` не является названием, статьи не размечены тегами;
  - статьи `art_dtkt_*` обрезаны пейволом;
  - `dps_cv_buklet_deklar_orenda.pdf` — двухколоночная верстка;
  - ловушка «устаревшая версия»: ставка ПДФО 18% (до 23.10.2026) и 5% (Закон №4903);
  - ловушка «похожие документы»: аренда земли, налог на недвижимость, аренда бизнесу,
    налоговая скидка для арендатора.
