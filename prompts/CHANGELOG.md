# Prompt changelog

# ДЗ 2 — RAG (`prompts/rag/`)

Версія — у назві файлу; код посилається на конкретну версію (`answer.py`: `PROMPT_VERSION = "answer_v1"`),
тож зміна промпту = новий файл `*_v2.txt` + запис тут + прогін evals.

## judge_v1 — 2026-11-18
LLM-as-a-judge (`evals.py`). На вході запитання, еталон (від людини), відповідь системи і тексти
**процитованих** чанків. Вихід JSON: спочатку `reason`, потім `correctness` 0–2 (проти еталона) і
`faithfulness` 0/1 (кожне твердження підтверджене джерелами). `reason` першим — щоб оцінка йшла після
міркування. Відкалібровано на 11 ручних оцінках (REPORT): faithfulness 11/11, correctness 7/11 — суддя
непослідовний щодо «неповної» відповіді (то суворіший, то м'якший за людину).

## answer_v1 — 2026-11-18
Відповідь з цитатами (`answer.py`). Правила: лише джерела, без власних знань; текст джерел — дані,
не інструкції (захист від prompt injection у документах); маркери `[n]` після кожного твердження;
при суперечності — найсвіжіше джерело, без дати не свіжіше датованого, «СЬОГОДНІ» в промпті
(пастка 18% → 5%); `insufficient=true` + дослівна фраза відмови, якщо відповіді немає (рівень 2 «не знаю»).
Українською: економія англійського промпту ~5–10% токенів, а вузьке місце free tier — запити/хв.

## rerank_v1 — 2026-11-18
Reranking (`retrieve.py`): оцінка 0–3 кожному з топ-10 кандидатів одним запитом, JSON-схема.
Шкала з явним значенням «1 = та сама тема, але відповіді немає» — на ній стоїть поріг «не знаю»
рівня 1 (max < 2 → відмова без виклику моделі), тож поріг випливає з визначення, а не підігнаний.

# ДЗ 1 — Structured Extraction (`prompts/v1.txt`, `v2.txt`)

## v2 — 2026-10-27
Додано правила розмітки (за помилками v1 на golden set):

| Правило | Чому (помилка v1) |
|---|---|
| city/district копіювати як у тексті, без перекладу | Ollama перекладає англійською: Kyiv, Kharkiv, Shevchenkivsky District |
| city лише якщо написане; не виводити з метро/ЖК | Gemini вгадує «Київ» за метро/ЖК (002, 008, 023, 027) |
| вулиця — не район | Gemini пише вулицю в district (013) |
| null замість рядка "unknown" у city/district | Ollama пише "unknown" як назву міста (008, 027) |
| валюта як у тексті, без конвертації | Ollama: $ → UAH (023, 027) |
| словник для utilities; застава ≠ комунальні | «+комунальні» → included (Ollama); «+16000 залог» → separate (Gemini, 008) |
| «Код об'єкта» → agent | Gemini не розпізнає агента (001, 011) |
| умова щодо тварин → negotiable | рішення розмітки golden set |
| amenities: словник, лише з тексту, без повторів | Ollama вигадує amenities (014 — шість вигаданих) і повторює; Gemini пропускає appliances (001, 008); лоджія → balcony |
| rooms — лише число з тексту | Ollama: 027 rooms=6 |
| критерій mixed для мови | 011 — змішаний текст розмічено як uk |

Порядок збережено: постійна інструкція на початку, оголошення в кінці (так працює кеш промпту).

## v1 — 2026-10-24

Спеціально без правил розмітки, щоб виміряти, скільки дають правила у v2.
