# Prompt changelog

## v2 — 2026-10-27
Додано правила розмітки (за помилками v1 на golden set):

| Правило | Чому (помилка v1) |
|---|---|
| city/district копіювати як у тексті, без перекладу | Ollama перекладає англійською: Kyiv, Kharkiv, Shevchenkivsky District |
| city лише якщо написане; не виводити з метро/ЖК | Gemini вгадує «Київ» за метро/ЖК (002, 008, 023, 027) |
| вулиця — не район | Gemini пише вулицю в district (013) |
| null замість рядка "unknown" у city/district | Ollama пише "unknown" як назву міста (008, 027) |
| валюта як у тексті, без конвертації | Ollama: $ → UAH (023, 027) |
| словник для utilities; застава ≠ комунальні | «+комунальні» → included (Ollama); «+16000 залог» → separate (Gemini, 008) |
| «Код об'єкта» → agent | Gemini не розпізнає агента (001, 011) |
| умова щодо тварин → negotiable | рішення розмітки golden set |
| amenities: словник, лише з тексту, без повторів | Ollama вигадує amenities (014 — шість вигаданих) і повторює; Gemini пропускає appliances (001, 008); лоджія → balcony |
| rooms — лише число з тексту | Ollama: 027 rooms=6 |
| критерій mixed для мови | 011 — змішаний текст розмічено як uk |

Порядок збережено: постійна інструкція на початку, оголошення в кінці (так працює кеш промпту).

## v1 — 2026-10-24
Baseline: коротка інструкція «витягни за схемою, не вгадуй, null/unknown якщо немає».
Спеціально без правил розмітки, щоб виміряти, скільки дають правила у v2.
